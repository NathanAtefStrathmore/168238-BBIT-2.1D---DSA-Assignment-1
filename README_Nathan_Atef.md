Answer the following questions:
1. What is the role of a class in a linked list?
The class is used in OOP to create objects. When used in a LinkedList, the class is the blueprint that determines the structure and the behaviours that the linkedlist would have. This includes all the variables and the functions that occur within the linkedlist.

2. What is the difference between a node and a linked list?
A node is 1 element, which is used for the storage of data, it also typically stores the pointer or reference to the next node. In a doubly linkedlist, it also stores the pointer to the previous node.

3. Why do we use None in next?
We use none in the case that the node we are refering to is the last node. This means that there is no next node to point to, so it wouldn't return a pointer.

4. How is a linked list different from a Python list?
A list in python is stored contiguously, meaning that it is all stored together in memory. However, a linkedlist's nodes are stored in different points within the memory, and thus it is referenced through pointers instead of indexing.

5. Why is OOP useful for data structures?
OOP is the best way to design classes and objects because it enforces strict rules on how we create objects. These objects oftentimes undergo strict rules such as encapsulation, abstraction, inheritance and polymorphism.
